# Simple-Registration-Form
A simple registration form built using HTML, CSS, and JavaScript with input validation to ensure that users enter valid information before submitting the form.

## Features
Name Validation: Checks whether the name field is empty and displays an error message if it is.
Email Validation: Checks whether the email address follows a valid format.
Password Validation: Ensures that the password contains at least 6 characters.
Real-Time Validation: Validates user input and displays error messages when the input is invalid.
Submit Button Control: Keeps the submit button disabled until all fields are correctly validated.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
This project was created to practice JavaScript form validation, event handling, conditional statements, and DOM manipulation.
